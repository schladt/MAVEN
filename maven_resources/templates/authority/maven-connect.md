# Connect an isolated client to configured memory

Confirm that MAVEN is installed and the owner has selected a private instance environment. Use `maven-memory --help` to inspect the shipped interface and `maven-memory context --project-id UUID` to retrieve the exact selected project's applicable authority through the verified runtime client. Do not search unrelated home directories, discover arbitrary AWS profiles or open private credentials to repair configuration.

If the runtime identity is unavailable, report the selected profile and ask the owner to perform the explicit approved login. Never run login or switch identities silently. If no deployment is configured, use the setup skill rather than invent an endpoint. Verify the caller and endpoint through the client before accessing memory.

Select an existing project using its private project configuration and start a new explicit session, or resume the exact owner-selected session. Read applicable authority and dependencies before project work. A clean new project may have no prior handover; distinguish that from an access failure. Do not assume another harness transcript, environment, local cache or remembered UUID provides context.
