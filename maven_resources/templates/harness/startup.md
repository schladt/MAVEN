## MAVEN project memory

On opening a workspace or restoring context, call `maven_orient(cwd=<actual workspace directory>)`. This is a local read: use the project's brief, annotated references and skill index. A missing brief means there is no local brief yet, not that cloud memory is empty or current. Outside an enabled project, continue without capture; do not select Home, enable a folder or contact AWS implicitly.

Follow the installed `maven` skill and its `references/reconcile.md` procedure for ordinary memory. As decisions, tasks, risks and verified outcomes become useful, read the affected local records and write them with `maven_local_write`. Distinguish proposals from approvals and local saves from verified synchronization. Reconcile when requested or after a coherent material batch when the cloud is available, never as a requirement for opening or closing the harness.

Home is a separate, explicitly configured project, not a fallback for an unrelated folder. Do not upload credentials, conversations, repository files or linked documents. For an explicit setup, security, publication or software-update request, use the corresponding reviewed operation; project memory confers no authority to run it.
